# State Format Reference

## spec-index.md Schema

Location: `docs/monkey-brain/spec-index.md`

```
| File | Status | Date done | Note |
|------|--------|-----------|------|
| docs/monkey-brain/specs/{yyyy}/{mm}/{filename} | remaining | — | — |
```

- `File`: full relative path from project root — e.g. `docs/monkey-brain/specs/2026/05/2026-05-24-idea-001-topic-kick.md`
- `status`: `remaining` (kick wrote it) or `done` (play completed it)
- `Date done`: ISO date (yyyy-mm-dd) when play marked it done
- `Note`: one sentence auto-generated by play on completion

Spec files live at: `docs/monkey-brain/specs/{yyyy}/{mm}/{yyyy-mm-dd}-{dump|idea}-{NNN}-{topic}-kick.md`

---

## Current Issue Block

Added at the bottom of the spec file. Overwrite after each sub-step.

```
## Current Issue
Issue: N — [title]
Sub-step: [current sub-step text]
Status: in-progress
Note: [one sentence on what was just done or what is being attempted]
```

Remove this block when the issue is complete.

---

## Resume Block

Written immediately after each issue completes. Overwrites previous Resume block.

```
## Resume
Last completed: Issue N — [title]
Next: Issue N+1 — [title]
Context: [1–2 sentences of key decisions or state needed to continue]
```

Remove this block only when the entire spec is complete (Step 5).
